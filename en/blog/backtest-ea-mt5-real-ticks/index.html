How to backtest an EA in MetaTrader 5 with real ticks

The MetaTrader 5 Strategy Tester is the best free tool to find out whether an EA makes sense before you risk money. Set up well, it simulates the market with your broker's real ticks. Set up badly, it shows you results you will never see live.

1. Open the tester

In MT5 press Ctrl+R (or View → Strategy Tester). In the Settings tab pick the EA under "Expert", the symbol (XAUUSD or whatever your broker calls it: GOLD, XAUUSD.m…) and the timeframe the EA is designed for.

2. Choose the period

Under "Date" select "Custom period" and set exact dates. Use at least several months and, if possible, include both trending and ranging phases. To check whether an EA is overfitted, enable "Forward": MT5 keeps the last part of the period aside and tests it separately with the same inputs.

3. Modelling mode: real ticks

Under "Modelling" choose "Every tick based on real ticks". MT5 downloads the ticks your broker actually recorded, with their variable spread. It is slower than "1 minute OHLC" or "Open prices only", but it is the only reliable mode for EAs trading M1 or M5 with tight stops. When the test ends, the report shows the "History quality": ideally 100% or very close.

4. Deposit, leverage and delays

Use a deposit similar to the one you will trade (for example 10,000 USD) and your account's leverage. Under "Delays" you can simulate execution delay: "Zero latency" is the ideal case; a random delay shows how much the result worsens with real execution. If the EA collapses with a small delay, it depends too much on perfect execution.

5. Inputs

In the "Inputs" tab check the values. If the EA comes with an optimised .set file, load it with right-click → Load. Note that MT5 remembers the last values used, so if you have run tests before, use right-click → "Defaults" or reload the .set to start clean.

6. Read the report

Press "Start" and, when it finishes, open the Backtest tab. The figures that matter most:

  • Total net profit and how it compares with the deposit.
  • Equity drawdown maximal: the worst fall, including open trades.
  • Profit factor: gross profit divided by gross loss. Above 1.2 over many trades is already interesting.
  • Recovery factor: net profit divided by maximum drawdown.
  • Number of trades: under 100 the result may be chance.
  • Maximum consecutive losses: prepares you for losing streaks.

The "Graph" tab shows the balance and equity curve. Look for a steady climb, not a single jump.

7. Save the report

Right-click the report → Report → HTML saves a full report with every trade. It is useful for comparing with live results later.
